# REBOND

# Cartographie des capacités métier

Version 1.0

---

# 1. Objet du document

Ce document définit les capacités métier de REBOND.

Une capacité métier représente ce que le système doit être capable de réaliser indépendamment de toute implémentation technique, organisationnelle ou applicative.

Les capacités décrites ici constituent le référentiel métier de référence permettant :

* de structurer la vision du produit ;
* d'orienter les choix fonctionnels ;
* d'organiser les travaux ;
* de définir les responsabilités ;
* d'évaluer la couverture fonctionnelle du système.

---

# 2. Mission de REBOND

La mission de REBOND est de transformer des traces documentaires en connaissances exploitables.

Le système doit permettre d'identifier, relier, qualifier et faire évoluer les entités décrites par les documents afin de produire une représentation cohérente, sourcée et explicable du monde qu'ils décrivent.

Les entités concernées peuvent être :

* des personnes ;
* des familles ;
* des lieux ;
* des propriétés ;
* des organisations ;
* des biens ;
* des contrats ;
* des événements ;
* ou toute autre réalité laissant des traces documentaires.

---

# 3. Capacité centrale

## Reconstruire des entités à partir de traces documentaires

Cette capacité constitue le cœur de REBOND.

Elle consiste à :

* exploiter des documents ;
* identifier les informations pertinentes ;
* produire des connaissances ;
* relier les informations ;
* reconstruire des entités ;
* suivre leur évolution ;
* expliquer les résultats obtenus.

L'ensemble des autres capacités existe pour soutenir cette capacité centrale.

---

# 4. Architecture métier globale

Les capacités métier sont organisées autour de sept domaines.

1. Gérer le patrimoine documentaire
2. Produire la connaissance documentaire
3. Reconstruire les entités
4. Reconstruire les dynamiques historiques
5. Garantir la qualité de la connaissance
6. Explorer et valoriser la connaissance
7. Faire évoluer la connaissance

# 12. Positionnement stratégique

REBOND n'est pas un logiciel de généalogie.

La généalogie constitue l'un des usages possibles du système.

REBOND est une plateforme de reconstruction documentaire capable de transformer des traces dispersées en connaissances structurées.

Son cœur de valeur réside dans sa capacité à :

* identifier les entités ;
* reconstruire leurs relations ;
* suivre leurs évolutions ;
* expliquer les résultats ;
* gérer l'incertitude ;
* produire une représentation cohérente du passé.

L'arbre généalogique, la carte historique, la chaîne de propriété ou le réseau social historique ne sont que différentes vues produites à partir du même patrimoine de connaissances.
