# REBOND

# Catalogue des règles métier

Version 1.0

---

# 1. Objet du document

Ce document définit les règles métier fondamentales de REBOND.

Une règle métier est une contrainte, un principe ou un mécanisme de raisonnement utilisé pour construire, valider ou faire évoluer la connaissance.

Les règles décrites ici sont indépendantes de toute implémentation technique.

---

# 2. Principes fondateurs

## RM-001 : Toute connaissance doit être traçable

Toute information doit être reliée à au moins une source.

### Conséquences

Impossible de créer une connaissance sans justification.

---

## RM-002 : Une source ne constitue pas nécessairement une preuve

Une information observée peut être erronée.

La source documente l'observation.

Elle ne garantit pas sa véracité.

---

## RM-003 : Le doute est une connaissance

Une hypothèse ou une contradiction doit être conservée.

Elle ne doit pas être supprimée au motif qu'elle est incomplète.

---

## RM-004 : Toute connaissance peut être remise en question

Aucune reconstruction n'est définitive.

Toute nouvelle preuve peut modifier une conclusion existante.

---

# 3. Règles documentaires

## RM-101 : Un document appartient à une source

Un document ne peut exister sans origine documentaire.

---

## RM-102 : Une mention appartient à un document

Toute mention doit pouvoir être localisée dans un document.

---

## RM-103 : Une assertion doit être justifiée

Toute assertion doit être reliée à au moins une mention.

---

## RM-104 : Les interprétations multiples sont autorisées

Une même mention peut produire plusieurs assertions concurrentes.

---

# 4. Règles de réconciliation des personnes

## RM-201 : Deux personnes ne sont jamais fusionnées sans justification

Une fusion doit toujours être explicable.

---

## RM-202 : Les homonymes sont présumés distincts

Deux personnes portant le même nom sont considérées différentes tant qu'aucune preuve ne permet leur rapprochement.

---

## RM-203 : Les variantes orthographiques sont présumées compatibles

Les différences d'orthographe ne suffisent pas à distinguer deux individus.

---

## RM-204 : Les incohérences majeures bloquent la fusion

Exemples :

* décès antérieur à la naissance ;
* présence simultanée dans des lieux incompatibles ;
* générations impossibles.

---

## RM-205 : Une identité peut rester incertaine

Le système doit permettre de conserver plusieurs scénarios.

---

## RM-302 : Une filiation peut être hypothétique

---

## RM-402 : Un lieu peut changer de nom

---

## RM-403 : Un lieu peut changer de périmètre

* identité du lieu ;

# 17. Règles de réconciliation (algorithme)

## RM-1501 : Règles bloquantes

Les conditions suivantes bloquent tout rapprochement, sans scoring.

* Décès antérieur à la naissance.
* Filiation biologiquement impossible.
* Présence simultanée dans des lieux incompatibles.
* Contradiction majeure sur des attributs non orthographiques.

Si une règle bloquante est déclenchée, le rapprochement est refusé.

---

## RM-1502 : Critères de scoring pour les personnes

| Critère            | Poids |
| ------------------ | ----: |
| Nom                |    20 |
| Prénom             |    15 |
| Âge / dates        |    15 |
| Conjoint           |    20 |
| Parents            |    20 |
| Lieu               |    10 |
| Profession         |     5 |
| Réseau relationnel |    10 |
| Signature          |    20 |

Les pondérations varient selon le type d'entité (lieu, bien, organisation).

---

## RM-1503 : Seuils de classification

| Score | Résultat      |
| ----- | ------------- |
| 0–39  | Distinct      |
| 40–59 | Possible      |
| 60–74 | Probable      |
| 75–89 | Très probable |
| 90+   | Quasi certain |

---

## RM-1504 : Validation obligatoire

Aucun rapprochement n'est appliqué sans validation humaine explicite.

---

## RM-1505 : Explicabilité obligatoire

Toute proposition de rapprochement doit exposer :

* les critères utilisés ;
* les poids appliqués ;
* le score calculé ;
* les éléments favorables ;
* les contradictions observées.

# 18. Règles d'extraction assistée

## RM-1601 : Toute suggestion est en attente de validation

Une proposition automatique ne devient jamais une mention sans validation humaine.

---

## RM-1602 : Une suggestion rejetée est conservée

Le rejet d'une suggestion est tracé.

Il ne disparaît pas du système.

---

## RM-1603 : Une suggestion validée produit une mention

La validation crée une mention rattachée à la transcription source.

---

## RM-1604 : Le moteur ne décide pas

Le moteur d'extraction propose.

L'humain arbitre.

---

## RM-1605 : La confiance d'une suggestion est informative

Le score de confiance d'une suggestion oriente l'humain.

Il ne détermine pas la décision.

---

# 19. Principe directeur

REBOND n'est pas un moteur de stockage.

REBOND est un moteur de raisonnement documentaire.

Les règles métier ont pour objectif de permettre au système :

* d'agréger des preuves ;
* de gérer l'incertitude ;
* de reconstruire des entités ;
* d'expliquer ses conclusions ;
* de faire évoluer la connaissance dans le temps.

La qualité du système dépend directement de la qualité, de la cohérence et de l'explicabilité de ces règles.
